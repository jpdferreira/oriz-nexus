# ORIZ NEXUS — public concept site

Static one-page website for GitHub Pages.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/` — optimized real photographs from Quinta da Compra / the valley

## Deploy on GitHub Pages
Upload the full contents of this folder to the repository root, then enable **Settings → Pages → Deploy from a branch** and select the branch/root folder.

The page is intentionally public-facing only: mountain hospitality, landscape and valley stewardship. It does not disclose the underlying Nexus business or scale model.

Contact shown on the website: `jp@quintacompra.com`.
