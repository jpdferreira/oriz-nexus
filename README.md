# ORIZ NEXUS — static website

A single-page public-facing concept site for ORIZ NEXUS. It intentionally avoids the underlying business model, technology layer, licensing/scaling strategy or any other confidential strategic element.

## Files
- `index.html` — page structure and copy
- `styles.css` — all styling and responsive behaviour
- `script.js` — language toggle, header state and reveal effects

## Deploy on GitHub Pages
1. Create a GitHub repository (or use the existing Quinta da Compra repository).
2. Upload the three files to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. If `quintadacompra.com` already points to GitHub Pages, preserve the existing `CNAME` file when replacing the site.
